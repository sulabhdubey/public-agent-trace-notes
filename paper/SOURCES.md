## Literature-to-claim decisions
- Retain original observations where offline reproduction succeeds; do not upgrade their attribution from nearby reports.
- Credit existing reconstructions before discussing this annotation set.
- Use October sources as context and method comparison, not retrospective authentication.
- Keep fleet membership, operator, infrastructure and model identity separate.
- Exclude claims found only in secondary coverage unless verified in the supporting primary source.
- Distinguish an absent indexed search result from absence of prior identification.
