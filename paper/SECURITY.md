# Security and evidence handling

This package supports passive historical analysis. It contains no recovered payload program and should not be used to replay incident requests, test discovered credentials, contact live agents or probe third-party systems.

Public metadata does not grant permission to use an account, endpoint or credential. Treat referenced materials and contributed files as untrusted data. Do not place credentials, customer information, raw executable artifacts or private logs in public issues. Report a possible exposure privately to the affected service using its verified disclosure channel; this repository is not a substitute for that channel.

The offline verifier uses bounded standard-library parsing. Package checks cover declared files and tested behavior, not every possible secret, parser vulnerability, historical source or host. A local successful check is not an endpoint-security certification. Do not disable antivirus, sandboxing, TLS validation or access controls for reproduction.

Before publication, recheck the exact archive and repository visibility. Before redistribution of new source material, review its license, redaction and audience. Before acting on a current advisory, refresh the official source and affected versions. No regulatory-compliance claim is made.
